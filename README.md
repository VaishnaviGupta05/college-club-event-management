# College Club Event Management Website

A responsive event management website for college clubs, built with plain HTML, CSS, and JavaScript.

## Features

- Student-facing home page with club intro and featured event
- Event listing page with search and category filter
- Event registration form with validation
- Admin dashboard to add, edit, and delete events
- Registration management with filtering/search
- Responsive layout for desktop, tablet, and mobile
- Data persisted in localStorage
